# Test Plans

Default to one plan for a representative complete beta journey through the full Orchestration. Link the specifications under test, identify the exact candidate, use a compact claim ledger, define material stop conditions, and plan independent inspection of durable effects.

Create a focused plan only for a material boundary, an observed defect needing diagnosis, or uncertainty that blocks the beta decision. Name plans `YYYY-MM-DD-<scope>-test-plan.md`; use [`test-plan-template.md`](../_templates/test-plan-template.md) when helpful.
