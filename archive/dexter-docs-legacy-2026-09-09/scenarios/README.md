# Scenarios

Scenarios are optional focused diagnostics, not a required test suite. Create one only for a material authority, privacy, identity, history, recovery, or effect-truth boundary; an observed defect needing reproduction; or uncertainty that blocks the beta decision.

Every Scenario must name one or more exact Skills whose behavior it evaluates. A coordinated Scenario names all Skills in scope. If no Skill runs and the check evaluates only a host surface, transport, package, dependency, or tool, record it as an Experiment or static validation rather than a Scenario.

The default complete experience belongs in a test plan or mediated Cowork session kit. When a reusable diagnostic is justified, name it `<descriptive-scenario>.md`, assign a revision, and use [`scenario-template.md`](../_templates/scenario-template.md) when helpful.
