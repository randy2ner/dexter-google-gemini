# Test Results

Store one immutable consolidated result for each complete beta journey. It should identify the exact candidate, summarize the journey, link exercised requirements and specifications, separate operator reports from independently inspected effects, compile compatibility gaps, and define one coordinated rewrite scope.

Create a separate focused-diagnostic result only when a material finding or blocking uncertainty required an isolated check. Name records `YYYY-MM-DD-<experience-or-diagnostic>.md` and use [`test-result-template.md`](../_templates/test-result-template.md) only when its structure helps.
