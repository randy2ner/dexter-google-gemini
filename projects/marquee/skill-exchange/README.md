# Marquee Skill Exchange

This folder contains downloadable Marquee `.skill` packages.

- [`marquee-v0.1.0-production-test-candidate.skill`](marquee-v0.1.0-production-test-candidate.skill) is the current importable test candidate implementing the draft Specifications for evaluation.
- Editable source remains in [`../skills/marquee/SKILL.md`](../skills/marquee/SKILL.md).
- The package contains `SKILL.md` at its archive root, as required for Skill import.

A package is an exact handoff artifact, not editable source. Its existence does not accept the behavior it implements or prove that behavior on a Skill host. Replace it only when the Skill version changes, and keep the corresponding Test Plans aligned with that version.

Package availability does not establish connected OneDrive, Work IQ, CareerHub, or OneNote capability. Those behaviors remain subject to production-surface testing.
