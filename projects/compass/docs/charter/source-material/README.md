# Charter Source Material

Place user-provided vision material for the Compass charter here. This may include notes, exported conversations, rough drafts, diagrams, or other files written in the user's own words.

## Handling rules

- Preserve the original file unchanged so its statements remain traceable.
- Use a descriptive lowercase kebab-case name; add `YYYY-MM-DD` when the date received matters.
- Do not place `.SKILL` packages here.
- Do not treat source statements as approved requirements or validated facts.
- Label extracted statements as ideas, assumptions, constraints, decisions, hypotheses, open questions, or requirement candidates.
- Cite the source file and relevant section when carrying material into the charter draft.
- Identify conflicts, ambiguity, and missing charter topics rather than silently resolving them.
- Do not store credentials, personal data, tenant identifiers, or confidential material unless the repository and its access controls are explicitly approved for it.

After reviewing the source, Dexter should ask only the questions needed to clarify gaps and confirm interpretation. The user must explicitly approve the resulting charter.
