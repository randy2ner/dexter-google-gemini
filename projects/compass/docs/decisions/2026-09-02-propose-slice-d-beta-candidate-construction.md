## Context

Compass now has accepted shared contracts, graph schema, five-Skill responsibility boundaries, and one lifecycle Orchestration. Gate 0 still lacks the exact complete source/package set and disposable lifecycle fixture required by the compact full-beta strategy.

## Decision

Authorize the exact disconnected construction actions in the linked plan:

1. create complete Installation Interview, Daily Scan, Tracking Topic Interview, and Curator source at version `0.1.0-beta-candidate`;
2. revise Graph Governor source as version `0.2.0-beta-candidate` without changing the tested `0.1.0-experimental` specimen;
3. create and validate the wholly fictional `compass-beta-graph-v1` fixture and external restore baseline;
4. create or update five current Skill profiles;
5. build and inspect five deterministic `.skill` packages in `ready-for-test/`;
6. record disconnected source, fixture, package, and complete-candidate compatibility observations; and
7. update living registries only from those observed results.

Construction must stop when an accepted contract or responsibility requires revision. Prior source, incoming packages, tested packages, fixtures, completed test results, and confidence assessments remain unchanged.

## Authority granted

- Edit only the source, fixture, profile, package, inspection, and living-status paths named by the plan.
- Use only fictional disconnected content and local file/archive operations.
- Create packages but do not upload, install, activate, or invoke them.
- Materialize and restore only the new disposable fixture, never a personal, connected, or production graph.
- Record direct observations without claiming Cowork behavior or measured confidence.

## Explicit exclusions

This decision does not authorize:

- Cowork import, installation, activation, or invocation;
- Microsoft 365, Work IQ, OneDrive, or connected evidence access;
- writes to any connected, personal, or production graph;
- Gate 1 or any runtime test;
- full beta, deployment, publication, or release; or
- modification of immutable prior artifacts or completed evidence.

## Consequence

If completed successfully, Slice D may close Gate 0 and prepare a separate exact-package Gate 1 authorization. Gate 1 does not begin automatically.
