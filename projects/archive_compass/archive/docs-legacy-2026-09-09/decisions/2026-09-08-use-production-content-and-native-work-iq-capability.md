# Decision: Use production content and native Work IQ capability

- **Date:** 2026-09-08
- **Status:** accepted
- **Decider:** User / product owner
- **Applies to:** Next Compass production-content test package set

## Context

The prior candidate set retained laboratory constraints: synthetic modes, fixed retrieval limits, Email/Teams-only discovery, and categorical Work IQ prohibitions in Topic Interview and Curator. Those controls would reduce Cowork below its available capability and could cause the new installation to build an incomplete or artificial graph.

The next run is intended to build durable production content from the user's authorized work context. The resulting graph should also remain suitable for later separately authorized evaluation or training uses.

## Decision

1. The package set is designated for production-content testing, not synthetic rehearsal and not general production release.
2. Skills never offer, inject, or substitute sample, fictional, fixture, or synthetic evidence during this workflow.
3. Within the purpose and scope the user authorizes, Skills use all relevant Work IQ capabilities Cowork exposes without arbitrary source-type or numeric result caps.
4. Skills use native continuation or pagination when available and attempt complete relevant coverage.
5. Permissions, Microsoft protection controls, explicit user purpose, relevance, retention minimization, and review before durable writes remain mandatory boundaries.
6. Missing capability, inaccessible evidence, or incomplete enumeration is reported directly and never inferred or presented as complete.
7. Installation may use Work IQ to discover proposed foundational CSPs, Topics, People, and relationships.
8. Daily Scan may use all relevant Work IQ evidence for the selected period; only evidence with verified durable chat or email Conversation identity becomes a Conversation under the current schema.
9. Tracking Topic Interview and Curator may retrieve Work IQ evidence when the user explicitly authorizes that retrieval for the current Topic or review purpose.
10. Graph Governor remains evidence-content neutral. It validates declared authority, provenance references, graph structure, source identity, and effects without independently interpreting Work IQ content.
11. Production graph content may support later evaluation or training, but this decision does not authorize export, disclosure, or submission to any model-training system.

## Consequences

- Shared contracts, four evidence-consuming Skills, Graph Governor mode language, orchestration, specifications, packages, and test records advance together.
- Synthetic evaluation cases remain repository test assets and are excluded from production-test packages.
- Connected partial writes remain `recovery-required`; production content never uses synthetic rollback.
- Runtime evidence must record the actual Cowork capabilities and coverage observed without copying identifying work content into Dexter.
