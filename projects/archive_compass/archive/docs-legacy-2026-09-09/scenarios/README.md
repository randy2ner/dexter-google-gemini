# Compass Scenarios

Every Compass Scenario names one or more exact Skills whose behavior it evaluates. A coordinated Scenario names every Skill and handoff in scope.

A check that invokes no Compass Skill and evaluates only Cowork, OneDrive transport, packaging, a dependency, or another tool belongs under [`../experiments/`](../experiments/) or in a static validation record. Do not assign it to a Skill merely to satisfy traceability.

The files under `onedrive-transport/` are compatibility pointers retained for historical links; their canonical no-Skill definitions are Experiments.
