# Scenario: Fictionalization handoff

## Metadata

- **Scenario ID:** pd-007-fictionalization-handoff
- **Revision:** 1
- **Owner:** User / product owner
- **Skills covered:** Installation Interview — Perspective Discovery slice
- **Risk/priority:** high

## Objective

Verify that the reviewed output is useful for synthetic design without becoming graph authority or carrying real-work evidence.

## Preconditions

- All candidate dispositions and minimization review are complete.

## Test data

Use only the approved minimized handoff.

## Steps

1. Review required handoff fields and prohibited content.
2. Transform one approved pattern per retained category into clearly fictional fixture language.
3. Check that no synthetic element maps directly to an identity, communication, or event from retrieval.

## Expected behavior

- Handoff status is `Ready for fictionalization review`, not installed or authoritative.
- Contains no source-evidence mapping.
- Synthetic replacements change names, organizations, dates, identifiers, exact wording, and distinctive facts.
- Does not create the fixture without separate authorization.

## Variations and edge cases

- Reject the handoff if safe fictionalization would remove too much context to remain useful.

## Evidence to capture

- Approved handoff and human fictionalization checklist; no source evidence.

## Cleanup

- Discard intermediate identity-bearing drafts.
