# Experiments

Experiments connect a hypothesis and controlled change to one or more scenario executions. Start from [`../_templates/experiment-notes-template.md`](../_templates/experiment-notes-template.md) and name records `YYYY-MM-DD-<concise-title>.md`.

Keep direct observations separate from interpretation. Link the exact Skill or Orchestration version, scenarios, test results, findings, and decisions. An inconclusive experiment is a valid record and should be preserved.
