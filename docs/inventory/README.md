# Inventory

The inventory is the Quadroplex-T3000 Computer's index of laboratory subjects. It makes ownership, versions, dependencies, status, and evidence discoverable without replacing detailed source records.

- Use [`skill-registry.md`](skill-registry.md) for Skills.
- Use [`orchestration-registry.md`](orchestration-registry.md) for multi-Skill workflows.
- Create a detailed profile from [`../_templates/skill-profile-template.md`](../_templates/skill-profile-template.md) when a registry row is not enough.

Update the relevant registry when a subject is introduced, versioned, deprecated, or removed. Link records using repository-relative paths.
