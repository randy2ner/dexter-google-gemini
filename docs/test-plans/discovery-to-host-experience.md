## Success decision

Determine whether Dexter can move a real project from an idea to an early end-to-end Skill host experience with understandable, aligned product knowledge and without recurring rejected ideas or excessive administrative work.

## Host compatibility profile

- **Required Dexter host behavior:** Load workspace instructions, discover the three workflow Skills, inspect and edit project files, and guide mediated testing.
- **Required project host behavior:** Determined from the candidate experience and verified with focused probes.
- **Another host:** Identify the product, probe only behaviorally material differences, and record a compatibility or adaptation hypothesis before the complete journey.

## Complete journey

| Stage | Skill or component | User decision | Observable effect or no-write outcome |
| --- | --- | --- | --- |
| Discover | Project Outcome Interview | Correct or accept candidate outcomes and boundaries | Charter, PRD, Specifications, and Test Plans align around a smallest coherent experience |
| Probe | Surface Capability Probe | Authorize any exact harmless connected operation | Required host capabilities become observed, conditional, unavailable, blocked, or remain unknown |
| Build | Dexter and project source | Direct implementation within the accepted boundary | Reviewable end-to-end candidate and package exist |
| Experience | Mediated Experience Test | Operate and direct the target AI surface | One representative journey completes or stops at a material boundary |
| Train | Coordinated revision | Accept product direction as it evolves | Affected living artifacts and source remain aligned and relevant behavior is retested |

## Material stop conditions

- Dexter selects an unreferenced project or silently promotes provisional direction.
- A rejected capability repeatedly returns without new user direction.
- Dexter begins a substantial change set before the user confirms its development plan or expands beyond the confirmed plan without renewed confirmation.
- Connected access, destructive effects, publication, release, or disclosure occurs without specific authority.
- Surface-reported success is treated as independently verified effect.
